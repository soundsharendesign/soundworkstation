SOUNDWORKSTATION

📖 SOUNDWORKSTATION 总使用教程

这是一个用于音色设计、编曲、和弦、节奏和课堂演示的多轨声音工作站。第一次使用时，建议先点击“播放”，确认四条轨道都能同时发声，再开始修改。

① 先认识四条轨道

轨1 旋律：负责主旋律，可以输入简谱数字 1～7。
轨2 和弦：负责和声，可以写 I～vii° 对应的级数。
轨3 贝斯：负责低音，可以输入 1～7。
轨4 鼓组：使用 K Kick、S Snare、CH Closed Hat、OH Open Hat、C Clap、T Tom、R Crash。

② 最简单的 DAW 用法

先确认右侧显示“使用 DAW 多轨”，然后点击 ▶ 播放。BPM 可以实时调整；“循环”打开后会不断循环。四条轨道的 Vol 可以单独控制。

例如轨1输入：1 2 3 5 | 6 5 3 2；轨3输入：1 1 5 5 | 6 6 3 3；轨4输入：K - CH - | S - CH -，就可以得到一个简单的旋律 + 贝斯 + 鼓组。

③ 简谱里的常用写法

1 2 3 = 连续四分音符；[1 2] = 两个八分音符；{1 2 3} = 三连音；1' = 高八度；1, = 低八度；- = 延长/空拍；| = 小节分隔。

④ 播放中也可以直接改谱

工作站支持播放中实时修改音符。直接修改轨1～轨4输入框，尚未播放的后续内容会采用最新设置，不需要先停止。

⑤ 音色设计：先选轨道，再调音色

在“独立通道条”里先选择 轨1 / 轨2 / 轨3 / 轨4，再设置这个轨道的音色。每条轨道都有独立的 OSC、Filter、ADSR、EQ、Drive、Chorus、Delay、Reverb 和 Pan。

常用思路：旋律可以提高 Cutoff 和一点 High；贝斯可以降低 Cutoff、增加 Low；和弦可以加入 Chorus / Reverb；鼓组一般保持快速 Attack 和较短 Release。

⑥ 和弦区怎么用

先选择当前调性，例如 C 大调。下面的 I、ii、iii、IV、V、vi、vii° 就是该调的七个自然级和弦。每张卡片都可以选择不同的和弦结构。

例如 C 大调的 V 级是 G：选择 7 就会得到 G-B-D-F；选择 9 会加入 A。选择 Maj7 / Maj9 / m7 / m9 / dim7 等时，实际播放的音程也会随选择改变。

⑦ 琶音怎么用

在和弦区的“和弦播放方式”选择：柱式、琶音·上行、琶音·下行、琶音·随机。然后按住任意和弦卡片即可试听；松开后停止。琶音速度可以选择十六分、八分或四分音符。

⑧ 自定义和弦

选择某张和弦卡片的 自定义，输入和弦名称和音程。音程使用“相对于根音的半音数”，例如：

0,4,7 = 大三和弦；0,3,7 = 小三和弦；0,4,7,10 = 属七；0,4,7,11 = 大七；0,4,7,10,14 = 属九；0,4,7,10,15 = 7♯9。

自定义和弦会跟随当前 Key 移调，所以换调后仍然保持相同的和弦结构。

⑨ Step Sequencer 怎么用

点击“使用 Step Sequencer”后，每一格代表一个起音位置。轨1 / 轨3 可以直接选择音高；轨2 选择和弦级数；轨4 连续点击可以循环切换鼓点。顶部可以选择四分、八分、十六分或三连音网格。

⑩ 键盘与课堂演示

最下面的键盘可以直接点击演奏。当前选择的轨道决定键盘使用哪一个音色。可以开关唱名、音名，也可以切换显示八度。和弦卡片被按住时，对应音高会在键盘上实时显示。

⑪ 节拍器

打开“独立节拍器”，选择拍号，例如 4/4、3/4、6/8。节拍器 BPM 与工作站 BPM 同步，适合课堂上讲节拍、速度和切分。

🎓 推荐课堂流程：先用键盘让学生试听 Saw / Square / Triangle / Sine → 再调 Attack / Decay / Sustain / Release → 用轨1写旋律 → 加轨2和弦 → 加轨3贝斯 → 加轨4鼓组 → 最后用 Chorus / Delay / Reverb 做空间处理。这样可以把“合成器原理 → 音色 → 和声 → 节奏 → 编曲 → 混音”连成一条完整的学习路径。
